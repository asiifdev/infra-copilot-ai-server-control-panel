Jika {process} tidak ikut pindah, apa pun yang bergantung padanya akan gagal setelah peralihan; jika ia berjalan di target pada port lain, semua yang masih memakai port {port} akan putus.
parity.par001.advice = Periksa apakah {process} memang harus berjalan di target. Jika ya, pasang dan jalankan di sana agar mendengarkan di port {port}, atau ubah semua konfigurasi yang menunjuk ke port {port}. Jika sudah tidak diperlukan, catat alasannya. Alat ini belum memperbaikinya secara otomatis.

parity.par008.title = Ada tugas terjadwal yang tidak punya padanan di target
parity.par008.explanation = Sumber menjalankan tugas terjadwal untuk {owner} ({schedule}): {command}. Di target tidak ada tugas yang cocok. Tugas seperti pencadangan atau pembersihan yang tidak ikut pindah mudah terlewat, dan kekurangannya bisa tidak disadari sampai hasilnya dibutuhkan.
parity.par008.advice = Periksa apakah tugas ini masih diperlukan. Jika ya, buat ulang di target dan pastikan tugas itu berjalan di sana; jika tidak, catat alasan tugas ini boleh dihapus. Alat ini belum menyalin tugas terjadwal secara otomatis.

parity.par010.title = Port {port} dapat dijangkau dari internet di {side}
parity.par010.explanation = {process} mendengarkan di port {port} pada alamat publik {side}. Siapa pun yang bisa menjangkau mesin itu dari internet dapat mencoba terhubung, kecuali firewall memblokirnya. Alat ini belum memeriksa aturan firewall, jadi tidak bisa memastikan apakah ada yang memblokir.
parity.par010.advice = Jika port {port} tidak perlu publik, ikat {process} ke alamat loopback atau blokir port itu dengan firewall. Jika harus tetap publik, pastikan memakai autentikasi dan selalu diperbarui. Alat ini tidak mengubahnya secara otomatis.

parity.reason.dev = server pengembangan
parity.reason.unsupervised = tidak diawasi pengelola layanan mana pun

parity.par006.title = {process} di target berupa {reason}
parity.par006.explanation = {process} melayani port {ports} di target tetapi berupa {reason}. Aplikasi seperti ini biasanya dijalankan manual atau dalam mode pengembangan: lebih lambat, dapat membuka fitur debug, dan tidak hidup kembali setelah crash atau reboot.
parity.par006.advice = Jalankan {process} di bawah pengelola layanan (systemd, PM2, atau container) dengan konfigurasi produksi, lalu pastikan ia hidup kembali setelah reboot. Alat ini tidak mengubahnya secara otomatis.

parity.par007.title = {name} di {app} menunjuk ke {host}:{port}, tempat tidak ada yang mendengarkan
parity.par007.explanation = Pengaturan {name} milik {app} merujuk ke {host} pada port {port}, artinya mesin yang sama, tetapi tidak ada program yang mendengarkan di port itu pada target. Aplikasi mungkin tetap menyala dan baru gagal saat pertama kali memakai layanan itu. Alat ini hanya membaca host dan port, tidak pernah nilainya, dan tidak menguji koneksi.
parity.par007.advice = Jalankan atau pasang layanan yang diharapkan {app} di port {port}, atau ubah {name} agar menunjuk ke tempat layanan itu sekarang berjalan. Alat ini tidak mengubahnya secara otomatis.
parity.par002.title = {name} di container {app} menunjuk ke {host}:{port}, yaitu container itu sendiri
parity.par002.explanation = Pengaturan {name} milik {app}, yang berjalan di dalam container, merujuk ke {host} pada port {port}. Di dalam container alamat itu adalah container itu sendiri, bukan host, padahal ada program yang mendengarkan di port {port} pada host. Listener apa pun di port itu dihitung, jadi ini bisa jadi alarm palsu bila container memakai jaringan host. Alat ini hanya membaca host dan port, tidak pernah nilainya.
parity.par002.advice = Ubah {name} ke alamat yang bisa dipakai container untuk menjangkau host atau layanan lain (misalnya nama container pada jaringan bersama), atau jalankan container di jaringan host dengan sengaja. Alat ini tidak mengubahnya secara otomatis.
parity.par009.title = {name} berjalan dengan versi mayor berbeda di target
parity.par009.explanation = {name} berversi {source_version} di sumber dan {target_version} di target. Versi mayor yang berbeda dapat mengubah format data atau pengaturan, sehingga layanan bisa menolak menyala atau memigrasi datanya. Alat ini hanya membandingkan tag versi container yang berhasil dibaca, bukan isi datanya.
parity.par009.advice = Periksa catatan rilis {name}, lalu kunci target ke {source_version} atau rencanakan peningkatan yang diuji dengan backup lebih dulu. Alat ini tidak mengubahnya secara otomatis.

parity.unknown.title = Temuan dari aturan {rule_id}
parity.unknown.explanation = Versi ini belum punya uraian untuk aturan {rule_id}.
parity.unknown.advice = Perbarui aplikasi, atau tinjau bukti temuan ini secara manual.
