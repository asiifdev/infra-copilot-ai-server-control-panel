# Licensing

**Status: provisional.** The license below is the current proposal. It must be confirmed (and
reviewed by a lawyer) before the first public release. See

## The license

The code in this repository is provided under the **GNU Affero General Public License v3.0 only**
(`AGPL-3.0-only`). The full, legally binding text is in [LICENSE](LICENSE), in English. No
translation of it is legally binding.

## What that means in plain words

This is a summary, not legal advice, and the text in `LICENSE` prevails.

- You may use, study, change and share the software, including for commercial purposes.
- If you distribute it, you must keep it under the same license and provide the source code.
- **If you let others use a modified version over a network** (for example as a hosted service),
  you must offer those users the source code of your modified version. This is the difference
  between the AGPL and the plain GPL.
- There is no warranty.

## Open core

The project intends an open-core model: this open-source core plus separately offered paid editions
(extra limits, licensing, hosted cloud). The commercial parts live outside this repository. Nothing
in the open core is meant to be disabled on purpose to push anyone to a paid edition.

## What is still open

- **The license itself.** `AGPL-3.0-only` is the proposal. The alternatives (for example
  `AGPL-3.0-or-later`, or a source-available license) have not been ruled out by a lawyer.
- **Contribution terms.** [CONTRIBUTING.md](CONTRIBUTING.md) uses the Developer Certificate of
  Origin (DCO) sign-off for now. A DCO does **not** let the project relicense your contribution
  under other terms. If the maintainers want to also sell commercial licenses for the same code
  (dual licensing), contributors would have to sign a Contributor License Agreement (CLA) or assign
  copyright. That decision is open and affects every contributor, so it is better made before
  outside contributions arrive.
- **Copyright holder.** Source files and notices use "Nodivara contributors" until the legal
  owner is named.
- **The name.** "Nodivara" is the name chosen by the owner (decision 0019). The owner reports
  it is still available and unique. That is not a clearance: a formal trademark search (WIPO, USPTO
  and other relevant registers) has not been done, and domain and handle availability (GitHub, npm,
  Docker Hub) is not the same as trademark rights.

## Why no Indonesian copy of the license

A translation of a license can change its meaning, and unofficial translations are not legally
binding. For that reason only the original English text is provided as `LICENSE`, with the
Indonesian explanation in [LICENSING.id.md](LICENSING.id.md).
